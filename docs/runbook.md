# Local fleet incident runbook

1. Run `python -m agent.operator --pki PATH list`. It follows every listing page automatically; optional `--page-size 1..100` changes per-RPC work. Compare desired/applied versions, `last_seen_ms`, `last_sequence` and `clock_skew_ms`. The certificate selects the tenant; other tenants' devices are absent. Custom clients must follow `next_page_token` until empty. If a pre-pagination client receives `INVALID_ARGUMENT`, regenerate it against the corrected request schema instead of increasing its receive limit.
2. Read agent JSON logs. `sampling_paused` means its durable journal reached capacity. `reconnect` includes gRPC status/details. A growing queue with `UNAVAILABLE` suggests network/server trouble. `UNAUTHENTICATED` or `PERMISSION_DENIED` requires registration/certificate investigation. Repeated `FAILED_PRECONDITION` or `ALREADY_EXISTS` must be investigated instead of deleting the spool.
3. Read server `ready`, `auth_rejected` and `committed` events. Commits identify tenant/device, cumulative ACK and accepted/duplicate counts. These are local diagnostic logs, not a tamper-proof audit store or exported metrics system.
4. Inspect a stopped agent's SQLite file with `SELECT * FROM state; SELECT min(sequence),max(sequence),count(*) FROM spool;`. Use SQLite backup for a consistent live copy; copying only the main file while WAL is active can omit commits. Never clear an unacknowledged journal to silence an alert.
5. Restore connectivity and start the same database/spool. Replay is automatic. Check contiguous telemetry, zero remaining queue rows and configuration convergence. Duplicate replay after a lost ACK is expected; altered content under the same sequence is not.
6. Issue `config DEVICE --expected CURRENT --interval-ms VALUE` to change sampling. On `ABORTED`, inspect the newer version before retrying. Use `revoke DEVICE` to reject the next frame from a compromised identity, including on an existing stream. Replacement provisioning is a deliberate operator procedure outside this demo.

`python -m scripts.experiment` automates the socket cut, SIGKILL and recovery sequence. Its measured timeline is in `evidence/failure-experiment.json`. A synthetic one-hour clock offset verifies that device wall time cannot change sequence ordering.
